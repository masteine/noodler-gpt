# Noodler — концепція

Легкий веб-застосунок для гітариста: відкрити файл Guitar Pro, програти його, увімкнути метроном, підлаштувати гітару. Нічого більше.

## 1. Ідея в одному абзаці

Є Guitar Pro (важкий, платний, десктопний) і Songsterr (онлайн, але це сервіс з бібліотекою, підпискою й акаунтами). Noodler — це ані те, ані інше: статична веб-сторінка, яку відкриваєш, кидаєш у неї свій `.gp` файл і граєш. Без реєстрації, без бібліотеки пісень; єдиний серверний шматок — крихітна функція пошуку відео на YouTube, без якої все інше працює. Працює офлайн після першого завантаження. Три інструменти в одному вікні: **плеєр табулатур**, **метроном**, **тюнер** — плюс **бектрек**: таб можна грати під оригінальний запис із YouTube.

## 2. Для кого і навіщо

- Гітарист, який розбирає пісні по табах і має власну колекцію `.gp5` / `.gpx` / `.gp` файлів.
- Сценарій «сів позайматись»: відкрив вкладку, підлаштував гітару, увімкнув таб на 70 % темпу, зациклив складний такт, грає.
- Телефон або планшет на пюпітрі так само важливий, як ноутбук.

## 3. Що входить (MVP) і що ні

### Входить

**Плеєр**
- Відкрити файл: drag-and-drop, кнопка «Відкрити», список нещодавніх (зберігається локально в браузері).
- Формати: Guitar Pro 3, 4, 5 (`.gp3/.gp4/.gp5`), Guitar Pro 6 (`.gpx`), Guitar Pro 7/8 (`.gp`). Бонусом MusicXML.
- Рендер табулатури та нотного стану (перемикач: таби / ноти / обидва).
- Відтворення із курсором, що біжить по нотах, і автопрокруткою.
- Швидкість 25–150 % без зміни висоти тону (speed trainer).
- Зациклення виділеного фрагменту (виділив такти мишею або пальцем).
- Вибір доріжки, mute / solo для кожної доріжки.
- Відлік перед стартом (count-in) і клік метронома поверх треку.
- Гарячі клавіші: пробіл — play/pause, стрілки — перемотка по тактах, L — loop, B — бектрек, M — мітка синхронізації.

**Бектрек з YouTube (ORIG / SYNTH)**
- Після відкриття файлу застосунок шукає оригінальний запис на YouTube за «виконавець + назва»; можна вставити посилання вручну.
- Режим ORIG: відео YouTube грає у плаваючому міні-вікні, alphaTab веде курсор синхронно (`PlayerMode.EnabledExternalMedia`). Транспорт, loop і швидкість керують відео. SYNTH — звичний синтезатор.
- Синхронізація: зсув початку (де у відео такт 1) плюс tap-мітки на першій долі такту; alphaTab інтерполює темп між мітками (sync points).
- Вибране відео й мітки зберігаються для файлу локально.

**Метроном** (працює і без відкритого файлу)
- Темп 30–300 BPM, tap tempo.
- Розмір (2/4, 3/4, 4/4, 6/8, 7/8 тощо), акцент на першу долю.
- Підрозділи: чверті, восьмі, тріолі, шістнадцяті.
- Візуальний маячок долі (великий, видно з відстані).
- Кнопка «взяти темп із табу», якщо таб відкритий.

**Тюнер**
- Мікрофон → визначення частоти → нота + відхилення в центах на шкалі.
- Хроматичний режим плюс пресети: Standard, Drop D, Eb Standard, Open G, бас 4/5 струн.
- Кнопка «взяти стрій із доріжки табу»: якщо в файлі доріжка в Drop C, тюнер пропонує Drop C.
- Еталонний тон (програти A4 = 440 Гц або будь-яку струну), калібрування 430–450 Гц.

**Загальне**
- PWA: встановлюється на домашній екран, працює офлайн.
- Світла та темна тема, велика тач-зона для планшета.
- Усі дані (нещодавні файли, налаштування) лише в браузері користувача.

### Не входить (свідомо)

- Редагування табів. Це не редактор.
- Акаунти, хмара, синхронізація.
- Каталог табів з інтернету. Користувач приносить свої файли; з інтернету шукається лише відеозапис пісні як бектрек.
- Запис себе, експорт аудіо, друк у PDF.
- Будь-яка соціальна функціональність.

## 4. Технічний стек

Принцип: «швидко» тут означає **не мати зайвого**, а не «переписати все на Rust». Критичні за часом речі (синтез звуку, визначення висоти тону, тікання метронома) живуть в окремих потоках браузера й не залежать від фреймворку. Фреймворк лише малює кнопки.

| Шар | Вибір | Чому |
|---|---|---|
| Парсинг, рендер і програвання GP | **alphaTab** (TypeScript, MPL-2.0) | Єдина зріла відкрита бібліотека: читає GP3–GP8, малює таби в SVG, має власний синтезатор на SoundFont, який працює у Web Worker + AudioWorklet. Закриває ~70 % продукту одразу. |
| Мова | **TypeScript** | alphaTab і Web Audio — це JS-екосистема; інша мова лише додасть міст. |
| UI | **Svelte 5** | Компілюється в мінімальний JS без віртуального DOM; бандл у рази менший за React. Альтернатива для ще меншого — vanilla TS + Web Components, але тоді стан UI пишеться руками. |
| Збірка | **Vite** | Миттєвий dev-сервер, легкий продакшн-бандл, плагін для PWA. |
| Аудіо | **Web Audio API** | Метроном: планування кліків із випередженням (lookahead) з таймером у Worker, бо таймери головного потоку гальмують у фоновій вкладці. Тюнер: `getUserMedia` → `AudioWorklet` → алгоритм MPM або YIN. |
| Зберігання | **IndexedDB** (через `idb`) | Нещодавні файли та налаштування без сервера. |
| Хостинг | Статика на Vercel + одна serverless-функція `api/yt-search.ts` | Статиці потрібен лише HTTPS (мікрофон без HTTPS не працює). Функція ховає ключ YouTube Data API; без неї застосунок працює, лише пошук стає ручним. |
| Бектрек | **YouTube IFrame Player API** як зовнішнє медіа alphaTab | Витягувати аудіо з YouTube не можна; натомість alphaTab 1.6+ уміє брати час із зовнішнього плеєра й вести курсор за ним. Вбудовуємо з `youtube-nocookie.com`, скрипт підключаємо ліниво. |
| Тести | Vitest (логіка метронома, детекція тону на синтетичних сигналах), Playwright (smoke) | |

**Де доречна «швидка мова».** Якщо виміри покажуть, що детекція тону в JS не встигає на слабких телефонах, алгоритм MPM переписується на Rust → WASM і вставляється в той самий AudioWorklet. Це ізольований модуль на ~200 рядків, і робити його наперед не варто. Решта (синтез alphaTab, рендер SVG) вже оптимізована авторами бібліотеки.

## 5. Архітектура

```
┌───────────────────────────── Браузер ─────────────────────────────┐
│                                                                    │
│   UI (Svelte)                                                      │
│   ┌──────────┐  ┌───────────┐  ┌─────────┐                         │
│   │  Плеєр   │  │ Метроном  │  │  Тюнер  │   ← три вкладки/панелі  │
│   └────┬─────┘  └─────┬─────┘  └────┬────┘                         │
│        │              │             │                              │
│   ┌────▼─────┐  ┌─────▼──────┐ ┌────▼────────┐                     │
│   │ alphaTab │  │ Scheduler  │ │ PitchWorklet│  ← окремі потоки    │
│   │ worker + │  │ (Worker)   │ │ (Audio-     │                     │
│   │ synth    │  │            │ │  Worklet)   │                     │
│   └────┬─────┘  └─────┬──────┘ └────┬────────┘                     │
│        └──────────────┴─────────────┘                              │
│                    Web Audio API                                   │
│                                                                    │
│   ┌──────────────┐  updatePosition(ms)                              │
│   │ YouTube      │ ───────────────────► alphaTab (ExternalMedia)    │
│   │ iframe       │ ◄─── play/pause/seek/rate (IExternalMediaHandler)│
│   └──────────────┘                                                  │
│                                                                    │
│   IndexedDB: нещодавні файли, зв'язки «файл → відео + мітки»       │
└────────────────────────────────────────────────────────────────────┘
          ▲                                      │ GET /api/yt-search?q=
   Файл з диска / drag-and-drop                  ▼
                                     Vercel-функція → YouTube Data API
```

Три модулі незалежні й спілкуються через невелике спільне сховище стану (поточний темп, стрій активної доріжки). Це дає кнопки «взяти темп із табу» та «взяти стрій із доріжки» без сильного зв'язку між модулями.

## 6. Інтерфейс

Один екран, зверху три перемикачі: **Таб · Метроном · Тюнер**.

- **Таб**: нотний стан на весь екран, знизу тонка панель транспорту (play, темп %, loop, доріжка, метроном on/off). На телефоні панель транспорту липка знизу.
- **Метроном**: величезна цифра BPM, кнопки ±1 / ±5, tap, коло-маячок долі, розмір і підрозділи — другим рядом.
- **Тюнер**: стрілка/шкала в центах на весь екран, назва ноти великими літерами, під нею шість кружечків-струн обраного строю, які підсвічуються зеленим, коли струна в строї.

Усе має читатись з відстані 1–1,5 м, бо гітара в руках, а пристрій на столі.

## 7. Етапи

1. **Кістяк + плеєр** (1–2 дні). Vite + Svelte + alphaTab, відкриття файлу, рендер, play/pause, курсор, темп, loop, доріжки. Уже корисний продукт.
2. **Метроном** (1 день). Scheduler у Worker, кліки через осцилятор, tap tempo, акценти, зв'язок із темпом табу.
3. **Тюнер** (1–2 дні). Мікрофон, AudioWorklet, MPM/YIN, шкала, пресети строїв, зв'язок зі строєм доріжки.
4. **Поліровка** (1–2 дні). PWA та офлайн, нещодавні файли, гарячі клавіші, теми, тач-ергономіка, перевірка на iOS Safari.

Разом близько тижня до робочої версії.

## 8. Ризики та як їх гасимо

- **Політика автовідтворення.** Safari та Chrome не дають створити `AudioContext` без жесту користувача. Контекст створюємо на першому кліку по play/метроному/тюнеру.
- **SoundFont.** Вбудований Sonivox від alphaTab важить ~1,5 МБ. Кешуємо через service worker, показуємо прогрес завантаження. Для кращого звуку можна підключити інший SF2, але це опція, не MVP.
- **iOS Safari.** AudioWorklet і мікрофон там мають особливості (наприклад, частота дискретизації 48 кГц, пауза при згортанні). Тестуємо на реальному iPhone з етапу 3.
- **Старі `.gpx`.** alphaTab їх читає, але окремі файли з екзотичними ефектами можуть рендеритись неідеально. Тримаємо набір тестових файлів різних версій.
- **Фонова вкладка.** Метроном має не плисти, коли вкладка в фоні: тому планувальник у Worker, а не `setInterval` у головному потоці.
- **YouTube.** Квота безкоштовного ключа Data API ≈ 100 пошуків/день: відповіді кешуємо на CDN, є запасні шляхи (свій ключ, вставити посилання). Автор може заборонити вбудовування відео — показуємо помилку й пропонуємо інше. У режимі ORIG синтезатор мовчить: клік метронома, mute/solo і швидкості поза кроком 25 % недоступні. Офлайн бектрек не працює, SYNTH — працює.

## 9. Відкриті питання

- Чи потрібна підтримка MIDI-виходу (грати таб через зовнішній синтезатор)? Поки ні.
- Чи додати «речовий» звук гітари замість загального SoundFont? Відкладено до фідбеку.
- Чи загортати в Tauri для десктопного ярлика? PWA, ймовірно, достатньо.
