# Noodler

Веб-плеєр табулатур Guitar Pro з метрономом, тюнером і бектреком з YouTube. Відкриваєш `.gp` файл просто у
браузері, граєш під синтезатор або під оригінальний запис, зациклюєш складні такти, сповільнюєш темп.
Без реєстрації, без бібліотеки пісень, файл нікуди не надсилається.

**Спробувати:** https://noodler-gpt.vercel.app

Концепція та межі проєкту: [CONCEPT.md](CONCEPT.md).

## Що вміє

- **Плеєр табів.** Guitar Pro 3–8 (`.gp3`, `.gp4`, `.gp5`, `.gpx`, `.gp`) і MusicXML. Таби, ноти або обидва разом.
  Курсор біжить по нотах, автопрокрутка, вибір доріжки, mute / solo, клік метронома, відлік перед стартом.
- **Speed trainer.** Швидкість 25–150 % без зміни висоти тону. Зациклення всього треку або виділених тактів.
- **Бектрек з YouTube (ORIG / SYNTH).** Як у Songsterr: застосунок сам знаходить пісню на YouTube, і таб можна
  грати під оригінальний запис. Курсор іде синхронно з відео, зсув і темп підлаштовуються мітками.
- **Метроном.** 30–300 BPM, tap tempo, розміри 2/4–12/8, підрозділи, акцент, «Взяти темп із табу».
- **Тюнер.** Хроматичний, пресети строїв, «Взяти стрій із табу» з активної доріжки, калібрування A4.
- **Приватність.** Файли й нещодавні лишаються в IndexedDB браузера. На сервер іде лише рядок пошуку
  «виконавець назва». Відео вбудовується з `youtube-nocookie.com`, скрипти YouTube вантажаться тільки коли
  відкрито вікно бектреку.
- **Українська та англійська.** Мова береться з браузера, перемикач UA / EN праворуч у верхній панелі.
  Рядки інтерфейсу лежать у `src/lib/i18n/` (`uk.ts` — еталон, `en.ts` — переклад).
- **Темна й світла тема.** За замовчуванням як у системі, перемикач поруч із мовою. Кольори — CSS-змінні
  в `src/app.css`; шрифти Onest і JetBrains Mono лежать у бандлі, без запитів до Google Fonts.
- Працює на телефоні й планшеті на пюпітрі: на вузькому екрані навігація переїжджає вниз, доріжки й бектрек
  відкриваються нижніми аркушами.

## Як користуватись

1. Відкрий сайт, натисни **«Відкрити»** і вибери файл Guitar Pro, або перетягни його у вікно.
   Кнопка **«Демо»** завантажує вбудований риф, якщо своїх файлів немає під рукою.
2. Пробіл запускає відтворення. Виділи мишею або пальцем кілька тактів і натисни **L**, щоб зациклити.
3. Повзунок швидкості сповільнює трек. Клік і відлік вмикаються в транспорті.
4. Кнопка **«Бектрек»** (або **B**) відкриває вікно з YouTube. Вибери відео зі списку або встав посилання,
   перемкни **ORIG**, і таб гратиме під оригінал.
5. Вкладки **Метроном** і **Тюнер** живуть окремо. Відкритий таб при перемиканні не губиться.

### Гарячі клавіші

| Клавіша | Дія |
|---|---|
| Пробіл | грати / пауза |
| Esc | стоп |
| ← / → | на такт назад / вперед |
| L | зациклити (увесь трек або виділений фрагмент) |
| B | показати / сховати вікно бектреку |
| M | мітка синхронізації на першій долі поточного такту (режим ORIG) |
| T | tap tempo (у метрономі) |
| ↑ / ↓ | темп метронома |

### Бектрек: синхронізація з відео

- **ORIG** грає відео YouTube, alphaTab лише веде курсор. Пробіл, Esc, стрілки, loop і швидкість керують
  відео. Швидкість тут обмежена кроками YouTube (25–200 %, крок 25 %), а клік метронома, відлік і mute / solo
  недоступні. **SYNTH** повертає звичний синтезатор.
- **«Початок»** задає момент у відео, де звучить такт 1. Кнопка **«Зараз»** бере поточний час відео.
- Якщо темп запису «пливе», під час гри натискай **M** на першій долі такту. alphaTab інтерполює темп між
  мітками. **«Скинути»** прибирає всі мітки.
- Відео й мітки запам'ятовуються для файлу (ім'я + розмір) і підхоплюються при наступному відкритті.
- Якщо серверний пошук недоступний, вікно пропонує ввести власний ключ YouTube Data API (зберігається в
  localStorage) або відкрити YouTube і вставити посилання.

## Деплой на Vercel

Проєкт збирається як статичний сайт, плюс одна serverless-функція `api/yt-search.ts` для пошуку відео.

1. Імпортуй репозиторій у Vercel. Framework preset: **Vite**, build command `npm run build`, output `dist`.
   Файли в `api/` Vercel підхоплює автоматично.
2. Отримай ключ YouTube Data API v3: Google Cloud Console → створити проєкт → увімкнути
   «YouTube Data API v3» → Credentials → API key. Варто обмежити ключ лише цим API.
3. У налаштуваннях проєкту Vercel додай змінну середовища **`YT_API_KEY`** зі значенням ключа і передеплой.

Без `YT_API_KEY` сайт працює повністю, лише автопошук відео вимкнений: функція відповідає 404, і застосунок
пропонує ручні варіанти. Квота безкоштовного ключа близько 100 пошуків на день, відповіді кешуються CDN на добу.

## Розробка

```bash
npm install
npm run dev
```

Відкрити http://localhost:5173. Для перевірки серверного пошуку в dev задай у `.env.local` змінну
`VITE_API_PROXY` з адресою деплою, тоді `/api` проксіюватиметься туди (див. [.env.example](.env.example)).

| Команда | Що робить |
|---|---|
| `npm run dev` | dev-сервер із гарячим перезавантаженням |
| `npm run build` | продакшн-збірка в `dist/` |
| `npm run preview` | локально роздати `dist/` |
| `npm run check` | перевірка типів (svelte-check + tsc, включно з `api/`) |
| `npm test` | юніт-тести (Vitest) |
| `node --experimental-strip-types scripts/test-pitch.mjs` | алгоритм тюнера на синтетичних сигналах |
| `node --experimental-strip-types scripts/test-recent.mjs` | сховище нещодавніх файлів |
| `node --experimental-strip-types scripts/test-links.mjs` | сховище зв'язків «файл → відео» |
| `node --experimental-strip-types scripts/gen-fixture.mjs` | згенерувати тестовий `.gp` файл із демо-рифу |

### Стек

- [Vite](https://vite.dev/) + [Svelte 5](https://svelte.dev/) + TypeScript
- [alphaTab](https://alphatab.net/): парсинг Guitar Pro, рендер нот і табів, синтезатор на SoundFont,
  режим зовнішнього медіа (`PlayerMode.EnabledExternalMedia`) для бектреку
- Web Audio API: метроном (планувальник у Worker) і тюнер (мікрофон, алгоритм McLeod Pitch)
- YouTube IFrame Player API + YouTube Data API v3 через Vercel-функцію
- Vitest для юніт-тестів

### Структура

```
src/
  App.svelte            — оболонка з трьома вкладками: Таб · Метроном · Тюнер
  lib/player/
    Player.svelte       — плеєр на alphaTab: відкриття файлу, транспорт, доріжки, вигляд, режим ORIG/SYNTH
    demo.ts             — демо-риф у форматі alphaTex
  lib/youtube/
    BackingTrack.svelte — плаваюче вікно: відео, пошук, посилання, зсув і мітки
    handler.ts          — міст YouTube-плеєр ↔ alphaTab (IExternalMediaHandler, позиція кожні 50 мс)
    iframe.ts           — ледаче підключення YouTube IFrame API, створення плеєра
    sync.ts             — чисті функції над мітками синхронізації (FlatSyncPoint)
    search.ts           — пошуковий запит, клієнт /api/yt-search і запасний прямий виклик Data API
    parse.ts            — витягнути id відео з посилання
    settings.ts         — власний API-ключ користувача в localStorage
  lib/metronome/        — Metronome.svelte, metronome.ts (lookahead-планувальник), scheduler.worker.ts
  lib/tuner/            — Tuner.svelte, pitch.ts (MPM), mic.ts, tunings.ts
  lib/storage/          — IndexedDB: нещодавні файли (recent.ts) і зв'язки «файл → відео» (links.ts)
  lib/session.svelte.ts — спільний стан: темп, розмір і стрій відкритого табу
  lib/theme.svelte.ts   — світла / темна тема
  lib/ui/               — іконки, логотип, перемикачі мови й теми
api/yt-search.ts        — Vercel-функція пошуку на YouTube (потрібен YT_API_KEY)
scripts/                — перевірки без браузера й генератор тестового файлу
tests/fixtures/         — тестові файли
```
