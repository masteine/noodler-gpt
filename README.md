# Noodler

Легкий веб-плеєр табулатур Guitar Pro з метрономом, тюнером і бектреком з YouTube. Файл лишається у браузері;
єдина серверна частина — необов'язкова функція пошуку відео.
Концепція та план: [CONCEPT.md](CONCEPT.md).

## Стек

- [Vite](https://vite.dev/) + [Svelte 5](https://svelte.dev/) + TypeScript
- [alphaTab](https://alphatab.net/) — парсинг Guitar Pro 3–8, рендер нот і табів, синтезатор на SoundFont
- Web Audio API: метроном (планувальник у Worker) і тюнер (мікрофон, алгоритм McLeod Pitch)
- YouTube IFrame Player API як зовнішнє медіа для alphaTab (`PlayerMode.EnabledExternalMedia`) — режим ORIG
- Одна Vercel-функція `api/yt-search.ts` для пошуку відео (YouTube Data API v3, ключ лишається на сервері)
- Vitest для юніт-тестів

## Запуск

```bash
npm install
npm run dev
```

Відкрити http://localhost:5173, натиснути «Відкрити» і вибрати `.gp` / `.gp5` / `.gpx` файл,
або «Демо» для вбудованого рифу.

## Гарячі клавіші плеєра

| Клавіша | Дія |
|---|---|
| Пробіл | грати / пауза |
| Esc | стоп |
| ← / → | на такт назад / вперед |
| L | зациклити (увесь трек або виділений мишею фрагмент) |
| B | показати / сховати вікно бектреку |
| M | мітка синхронізації на першій долі поточного такту (у режимі ORIG) |

## Бектрек з YouTube (ORIG / SYNTH)

Замість MIDI-синтезатора таб можна грати під оригінальний запис, як у Songsterr.

- Після відкриття файлу застосунок шукає пісню на YouTube за «виконавець + назва» з табу (або з імені файлу).
  Кнопка «Бектрек» (B) відкриває плаваюче вікно з результатами; можна й просто вставити посилання на відео.
- **ORIG** — грає відео YouTube, alphaTab лише веде курсор; пробіл, Esc, стрілки, loop і швидкість керують відео.
  Швидкість у цьому режимі обмежена кроками YouTube (25–200 %, крок 25 %); клік метронома, відлік, mute/solo
  недоступні. **SYNTH** — звичний синтезатор.
- Синхронізація: «Початок» — момент у відео, де починається такт 1 (кнопка «Зараз» бере поточний час відео).
  Якщо темп запису «пливе», під час гри натискай **M** на першій долі такту: alphaTab інтерполює темп між мітками.
- Відео й мітки запам'ятовуються для файлу (ім'я + розмір) в IndexedDB і підхоплюються при наступному відкритті.
- Пошук: у продакшні — через `api/yt-search.ts` зі змінною середовища `YT_API_KEY` (Vercel). Без неї функція
  відповідає 404, і застосунок пропонує або ввести власний ключ YouTube Data API (зберігається в localStorage), або
  відкрити YouTube і вставити посилання. У `npm run dev` змінна `VITE_API_PROXY` проксіює `/api` на деплой
  (див. `.env.example`). Квота безкоштовного ключа ≈ 100 пошуків на день; відповіді кешуються CDN на добу.
- Приватність: відео вбудовується з `youtube-nocookie.com`, а скрипти YouTube завантажуються лише коли відкрито
  вікно бектреку. На сервер пошуку йде тільки рядок запиту («виконавець назва»), сам файл — ніколи.

## Метроном і тюнер

- Метроном: 30–300 BPM, tap tempo (клавіша T), розміри 2/4–12/8, підрозділи, акцент, «Взяти темп із табу». Пробіл — старт/стоп, ↑ ↓ — темп.
- Тюнер: мікрофон вмикається лише за кліком; хроматичний режим і пресети строїв; «Взяти стрій із табу» бере стрій активної доріжки; калібрування A4 430–450 Гц.
- Нещодавні файли зберігаються в IndexedDB браузера, нікуди не надсилаються.

## Структура

```
src/
  App.svelte            — оболонка з трьома вкладками: Таб · Метроном · Тюнер
  lib/player/
    Player.svelte       — плеєр на alphaTab: відкриття файлу, транспорт, доріжки, вигляд, режим ORIG/SYNTH
    demo.ts             — демо-риф у форматі alphaTex
  lib/youtube/
    BackingTrack.svelte — плаваюче вікно: відео, пошук, посилання, зсув і мітки
    handler.ts          — міст YouTube-плеєр ↔ alphaTab (IExternalMediaHandler, позиція кожні 50 мс)
    iframe.ts           — ледаче підключення YouTube IFrame API, створення плеєра
    sync.ts             — чисті функції над мітками синхронізації (FlatSyncPoint)
    search.ts           — пошуковий запит, клієнт /api/yt-search і запасний прямий виклик Data API
    parse.ts            — витягнути id відео з посилання
    settings.ts         — власний API-ключ користувача в localStorage
  lib/metronome/        — Metronome.svelte, metronome.ts (lookahead-планувальник), scheduler.worker.ts
  lib/tuner/            — Tuner.svelte, pitch.ts (MPM), mic.ts, tunings.ts
  lib/storage/          — IndexedDB: нещодавні файли (recent.ts) і зв'язки «файл → відео» (links.ts)
  lib/session.svelte.ts — спільний стан: темп, розмір і стрій відкритого табу
api/yt-search.ts        — Vercel-функція пошуку на YouTube (потрібен YT_API_KEY)
scripts/gen-fixture.mjs — експорт демо-рифу в Guitar Pro 7 (.gp) для тестів
tests/fixtures/         — тестові файли
```
